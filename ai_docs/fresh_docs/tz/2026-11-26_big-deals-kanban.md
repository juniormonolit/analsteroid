# ТЗ: Канбан больших чеков — удобство постановки задач (собрание 26.11.2026)

Источник: запись собрания 26.11, расшифровка whisper. Код сверен 27.11: `features/big-deals-kanban/ui/{TaskDrawerActions,
TaskDrawer,BigTaskCardView,CallsTab,DeadlineField,BigDealsKanbanPage}.tsx`, `features/tasker/ui/create/DealTaskDrawer.tsx`.

## Контекст

Директор работает **только в канбане**: колонки «Новое», «Нераспределённое», «Ждёт контроля». В «Сегодня» и другие разделы
не заходит. Концептуально всё устраивает, «быстро редактируется». Главная задача: **сделать удобной постановку задач для
любого РОПа**. Шаблоны вопросов наполнят сами, разработки не нужно.

## 1. Черновик задачи не должен пропадать (приоритет 1)

**Симптом:** директор пишет задачу менеджеру, уходит на другую вкладку и возвращается — окно постановки закрыто, текст
надо писать заново. **Сегодня так было три раза.** Второй сценарий: начал писать, вернулся в таблицу за показателем, текст пропал.

**Что известно по коду:** черновик — обычный `useState` в `TaskActions` (`TaskDrawerActions.tsx:34-43`). Он теряется,
когда закрывается шторка (клик мимо, Esc) и когда внутри шторки переключаешься на вкладку связанной задачи
(`TaskDrawer.tsx:149-156`: `RelatedSide` вместо `TaskActions` размонтирует форму). Тот же черновик у «В Задачник»
(`DealTaskDrawer` внутри `TaskActions`). Обработчика `visibilitychange` нет. Канбан перезапрашивается раз в 60 с,
refetch-on-focus не отключён. **В браузере не воспроизводили — сначала воспроизвести** сценарий «переключил вкладку
браузера → вернулся».

**Сделать:**
- Хранить черновик (бриф, вопросы, срок, исполнитель; и для «Назначить», и для «В Задачник») в `sessionStorage` по ключу задачи.
  Восстанавливать при открытии той же карточки, чистить после успешной отправки или по явной кнопке «Сбросить».
- Клик мимо шторки и Esc при непустом черновике — не закрывать молча: спросить или просто сохранить черновик (выбрать сохранение).
- Переключение вкладок внутри шторки не размонтирует форму (держать смонтированной, скрывать).
- Найти и устранить причину закрытия при возврате во вкладку браузера (refetch → смена карточки/ключа → размонтирование).

## 2. Время в задаче «В Задачник»

**Как сейчас:** у «В Задачник» только дата, по умолчанию сегодня + 2 дня (`DealTaskDrawer.tsx:132, 206`). На собрании
хотели «сегодня через 10 минут» — не смогли: «и здесь нет времени».
**Сделать:** то же поле срока, что у «Назначить» (`DeadlineField`: день + время, быстрые «Сегодня / Завтра / Послезавтра»).
По умолчанию — «Сегодня», через час.

## 3. Звонки свёрнуты

**Как сейчас:** во вкладке «Звонки и ИИ» первые 3 звонка с расшифровкой развёрнуты (`CallsTab.tsx:19, 141`).
**Сделать:** все звонки по умолчанию **свёрнуты** в строку (дата, длительность, направление, кто). Разворачиваются по клику,
плюс кнопка «развернуть все».

## 4. Видимость

- Выбранный менеджер в фильтре (на собрании — Стадник) выделять **ярче**: сейчас «никакой непонятно».
