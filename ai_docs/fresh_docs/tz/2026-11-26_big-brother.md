## Вопрос директора (дословно по смыслу)

«Завтра меня нет, я с пивасиком хочу посмотреть: что сделал Руденко сегодня». И второй вопрос — за месяц:
«у Павленко столько-то, у Руденко столько-то — кто сколько провёл, и есть ли корреляция с результатом».
На демо показали сводку по РОПам: задачи по источникам, охват, закрыто, ждут контроля, просрочено, продажи. Ответ директора:
«много всего, а мне надо вот это». Разработчик забрал на доработку.

  `follow` (закрыто, ждут контроля, принято, просрочено, возвраты), метрики отдела, подчинённые.

## 1. «День РОПа» — один экран на вопрос «что сделал X сегодня»

Выбор: РОП (или любой руководитель) + дата (по умолчанию сегодня). Показать **списком событий по времени**, без агрегатов:
- задачи, которые он **поставил** (кому, по какой метрике или сделке, через какой сервис) — ссылка на задачу;
- задачи, которые он **закрыл, проверил, вернул**;
- проведённые «Практики» и сессии с менеджерами (с кем, длительность);
- звонки (кол-во, минуты) и действия в канбанах;
- вверху одна строка итога: «поставил 9, закрыл 5, проверил 3, провёл 2 разбора, 41 мин звонков».
Каждое число и строка кликабельны и ведут на задачу или сделку. Сейчас кликабельны только задачи Задачника — сделать для всех источников.

## 2. «Месяц по РОПам» — сравнение и корреляция

Таблица: строки — РОПы, период — месяц / 30 / 90 дней. Колонки:
- **действия:** задач поставлено, разборов («Практик») проведено, на обучение отправлено, проверено;
- **результат команды:** продажи, % плана, CR сделка → бронь / продажа и их изменение к прошлому периоду.
Сортировка по любой колонке. Цель — увидеть, у кого много действий и есть рост, а у кого «проебано».
Сводку «всего 232 задачи, из них просрочено…» убрать с первого экрана в раскрывашку: директору не нужна.

## 3. Фильтр «команда РОПа»

На «Людях» и в «Дне РОПа» выбор «Команда Новикова» показывает самого РОПа **и** его менеджеров. Сейчас выбор роли даёт только
менеджеров, а команду можно найти лишь текстовым поиском по фамилии.
