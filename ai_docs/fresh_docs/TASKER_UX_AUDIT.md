следующий шаг; повторяющиеся подписи в ячейках; действия только по hover; разные навигации в одном разделе;
форматы дат «23.11–27.11» / «Пн, 23 нояб.» / «Вторник, 24 ноября» (⏳ P3). Правила, чтобы не повторялось, —
`DESIGN_GUIDELINES.md`, раздел «Экран не каркас».
